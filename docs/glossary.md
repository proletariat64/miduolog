# 米多错题本

收集数学与语文的作答，分析可能错因，通过独立复习减少重复错误。

## Language

**试卷原图**：保存题目、原作答及批改痕迹的图片。图片可以包含多道题，也可能只包含不完整题干或作答。

**导入任务**：把一份试卷原图转为可核对题目的一次处理，包含进度、结果及失败情况。再次选择相同内容的图片时，可以查看此前的导入任务。

**待核对题目**：已提取但尚未确认题干、原作答是否准确的题目。待核对不表示已确认做错。

**已入库错题**：经过核对、选择进入复习范围的题目。是否入库与错因是否已确认是两件事。

**可能错因**：根据作答提出、仍需孩子解释或后续复习验证的原因，区别于可以直接观察的出错位置。

**复习作答**：一次复习中对一道已入库题目的重新回答，关联本次使用的提示、批阅和异议。

**批阅结果**：对本次复习作答的判断，分为独立做对、提示后做对、仍不会和待确认。处理失败不是批阅结果，不计为做错。

**验证记录**：为验证软件而提交的测试作答及批阅，不代表女儿实际表现，也不参与正式复习推荐。
