# 米多错题本

保留题目、孩子原作答及批改证据，通过核对和独立复习减少重复错误。

## Language

**题目**：可独立作答、独立核对的一道问题。题号或排版变化不一定产生新题，数值、条件或所求问题变化则是不同题。

**共用材料**：多道题共同依赖的文章、题干或图形说明。小题独立保存时，仍与必要的共用材料关联。

**试卷原图**：保留题目、原作答与批改痕迹的来源照片。照片可能是整页、局部、答题纸，也可能包含残缺内容。

**上传批次**：一次选择的照片及其处理结果。它界定本次题目与答题纸的关联范围，不是题目的所属档案。

**导入任务**：将一张试卷原图转为可核对信息的一次处理，包含进度、结果与失败情况。同一原图可被不同上传批次复用。

**原作答**：照片中孩子对一道题的一次回答，包括答案、过程或可见的绘图。同题重新作答是另一条记录，同次作答重拍只是补充来源。
_Avoid_: 将老师订正或参考答案当作孩子答案

**老师批改**：原图中老师留下的勾叉、得分、评语和订正。未见批改与看不清批改是不同情况。

**AI 判断**：根据当前可用题目与作答给出的独立判断及依据。它不冒充老师批改，也不直接证明孩子已经掌握。

**作答状态**：对一次原作答的当前分类，包括待确认、错误、正确、部分正确或未作答。题目最近状态概括最近一次记录，曾错过的证据仍保留。

**无原作答**：目前未获得孩子原作答的题目。题目页没有作答，不等于孩子实际未作答或做错。

**待核对题目**：已保存但尚未确认题干与必要配图准确的题目。待核对与作答是否错误是独立判断。

**已入库错题**：经过核对并选择用于复习的题目。后续可以出现正确作答，进入复习范围与可能错因是否确认也是两件事。

**可能错因**：根据作答提出、仍需孩子解释或后续复习验证的原因，区别于可以直接观察的出错位置。

**重复候选**：可能与已有照片、题目或作答相同，需要对照处理的内容。相似不表示相同，同题也不表示同一次作答。

**未关联作答**：本批照片中可见、但尚不能明确对应本批题目的原作答。归属未明时不猜测题目，也不搜索历史题目认领。

**复习作答**：一次复习中对一道已入库题目的重新回答，关联本次使用的提示、批阅和异议。

**批阅结果**：对本次复习作答的判断，分为独立做对、提示后做对、仍不会和待确认。处理失败不是批阅结果，不计为做错。

**验证记录**：为验证软件而提交的测试作答及批阅，不代表孩子实际表现，也不参与正式复习推荐。
