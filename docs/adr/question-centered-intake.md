# 题目中心的录入边界

日常照片可能包含多题、共用文章、重复拍摄以及与题目分开的答题纸。录入服务以题目及每次原作答为核心，照片作为可复用证据，上传批次只限定本次材料关联范围；试卷名称等留为属性或标签，不建立题目必须从属于一份试卷的层级。

这使题目去重可以对比历史，同时答题纸归属严格限于本批；同题新作答、同次作答重拍和历史人工修改因此能分别保留。代价是需要显式维护来源、共用材料、作答历史和拆合谱系；复习服务通过录入接口取得题目快照，不直接修改录入数据。


上传在原图保存完成后封口；中断的批次显示可恢复的失败状态。重新选择同批原照片时，按本地内容摘要继续原批次，已完成识别不再调用模型。原图丢失时先要求补回照片，不把无来源任务反复送去识别。

照片候选同时比较版式指纹和内容墨迹，避免把留白、排版相近的不同页面当作重拍。所有相似结果仍需要人工选择，不自动丢弃。答题纸的自动归属等待本批失败及重复候选处理完成，并通过显式拆合谱系查找仍有效的题目；已移除题目不参与归属。

每张识别结果在成为可用结果前验证题目、作答和共用材料；历史坏结果在恢复时逐图隔离。作答历史只记录修改前后的事实字段，避免把查询结果中的历史再次嵌入历史。复习快照解析并冻结当时的共用材料，题目显示、提示与批阅使用同一份内容，后续修改材料不会改变已开始的复习。
